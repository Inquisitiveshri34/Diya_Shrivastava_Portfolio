Diya Shrivastava — portfolio design for Figma (11 Nov 2026)

How to open:
1. Open Figma and create a new design file.
2. Select all six .svg files and drag them onto the canvas
   (or use Main menu > File > Place image..., or copy an SVG's contents and paste).
3. Each screen arrives as its own frame with editable text layers and vector shapes.

Fonts used (all free on Google Fonts, built into Figma): Literata (600, plus 400 italic),
Public Sans (400/500/600), Roboto Mono (400/500/600), Noto Serif JP (600, for the seal).

Notes:
- Layers are grouped by HTML structure, not Figma auto layout, so spacing is fixed positions.
- On Home (laptop and phone) the header's DS seal and name are present but at 0% opacity,
  matching the design: they appear only after the headline scrolls away.
- Interactive states (About chart pills, Work's learning-projects toggle) are shown in their
  default state: chart on "Now", learning projects collapsed.

Colours: background #F5F7F2 · plum #6C3E66 · graphite #23262B · tint #EBF0E7 · plum tint #F3EAF1
